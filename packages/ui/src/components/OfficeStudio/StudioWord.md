# Word 编辑器

`StudioWord` 是 `OfficeStudio` 按需加载的 Word 内核，工具栏、字体选择、颜色、图片尺寸、查找、大纲和页眉页脚设置使用 ZUVI 控件。编辑结构采用 Tiptap / ProseMirror，文件编码由宿主完成。

支持正文、标题、字体字号、颜色和文字背景、粗体斜体下划线删除线、上下标、对齐、段落缩进间距、嵌套列表、表格及行列合并拆分、链接、水平线、显式分页、纸张方向与缩放。正文和默认页眉页脚各自保留编辑历史；受控更新被宿主拒绝时，画布恢复到宿主接受的模型。

开始栏的“新建样式 / 修改样式”提供可命名的段落样式、基础样式继承、后续段落、大纲级别、文字格式和段落布局。留空的格式沿用基础样式；修改基础样式会更新派生样式及关联段落，单独设置的不同格式保留。创建、修改、删除与应用进入正文撤销历史；页眉页脚中的关联段落也随全局定义更新。勾选自动更新后，正文中的直接格式修改会同步到此样式。Enter 在普通段落和列表中都应用配置的后续样式，并保留不同于原样式的直接文字格式。Word 字号控件的 1–409pt 范围与文件适配器一致，步进为 0.5pt。

样式定义保存在 `content.attrs.paragraphStyles`，使用 `StudioWordParagraphStyle` 类型；段落或标题通过 `attrs.paragraphStyle` 引用稳定标识。宿主可以只提供定义与关联，编辑器和文件适配器会解析继承。编辑产生的格式快照也属于文档 JSON，保存和恢复时应保留完整节点属性。一个文档最多 100 个自定义样式，名称唯一且不超过 80 个字符；循环继承、缺失引用和无效格式会在修改或导出前被拒绝。

DOCX 中写入原生 `w:style`、`basedOn`、`next`、大纲和自动更新属性，段落使用 `w:pStyle` 关联；取消继承的文字格式会写入原生覆盖。导入也保留支持范围内的原生自定义段落样式。未使用的已创建样式、继承关系和名称在重复保存重开时继续保留。

本地 PNG / JPEG 可通过文件选择或粘贴插入正文、页眉或页脚。点击图片进入图片工具，可设置宽高、锁定比例、修改替代文字、删除和撤销。单图最大 8 MiB，文件适配器限制全部嵌入图片为 25 MiB。不读取远程图片地址。

图片工具提供嵌入、四周、紧密、穿越、上下、浮于文字上方及衬于文字下方模式；“图片位置与环绕”弹窗可编辑水平/垂直基准、偏移或对齐、四侧文字间距、随文字移动、锚点锁定、重叠、表格内布局及层级。移动手柄支持拖动预览、Esc 取消和方向键微调；每次完整拖动提交一个撤销事务。模型使用图片节点的可选 `attrs.layout: StudioWordImageLayout`，位置和间距单位为 CSS 像素。导入的自定义紧密/穿越轮廓可保留，原生文件使用 EMU 定位和 `wp:anchor`。

连续画布按当前纸张预览浮动图。尚未提供完整自动分页，奇偶页内外侧、复杂避让及跨页环绕的排版精度仍需后续内核验收；原生 DOCX 保留支持范围内的定位和锚点数据，不能据此宣称全部 Word 布局对齐。

`header`、`footer` 是可选 `doc` 根节点。插入栏可以创建或聚焦默认页眉页脚，工具栏格式作用于当前区域。`page.headerDistance` / `footerDistance` 以 mm 表示，支持 0–80。`pageNumber` 行内节点的 `attrs.kind` 为 `current` 或 `total`，导出为原生 PAGE / NUMPAGES 域；画布显示字段占位值，页码由打开 DOCX 的排版程序计算。勾选“显示页码”会向已有页脚添加默认页码。

Ctrl / Command F 或 H 打开当前区域的查找与替换。匹配可以跨文字样式，支持大小写、Enter / Shift Enter 导航、单项与全部替换。替换使用纯文本和一个撤销事务。超过 10,000 处匹配时禁用全部替换并提示缩小查询范围；替换后的文本限制为 200 万字符。大纲列出正文标题并支持跳转。只读状态保留查找、标题导航、缩放和选择，关闭修改入口。

示例 DOCX 适配器位于 `docs/src/pages/collaboration/office-studio/studio-word-codec.ts`，支持内嵌或浮动 PNG / JPEG、单节默认页眉页脚、阿拉伯 PAGE / NUMPAGES 域和普通文字、列表、表格的真实文件往返。图形效果、裁剪、旋转、SVG、外链图片、修订、目录、不同首页、奇偶页、多节、复杂编号及未知域会明确拒绝，避免导出丢失对象。

画布使用连续纸张与显式分页。它没有 Office 的完整自动分页、字体度量和复杂版式兼容能力；页眉页脚画布预览显示在连续文稿的顶部和底部。DOCX 的纸张和页眉页脚距离供打开文件的排版程序使用。

验证入口：`StudioWord.test.tsx` 和 `docs/tests/office-studio-word.test.mjs`。测试覆盖实际编辑、只读、受控回退、图片缩放删除撤销、页眉格式、查找替换，以及真实 ZIP 内嵌图片、页眉页脚和页码域重复导出重开。

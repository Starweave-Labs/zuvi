# W027 表格打印重复表头

打印 HTML 将连续的顶部完整表头行放入原生 `thead`，其余行放入 `tbody`。正文中的非顶部表头不会被提升为重复表头。空页眉/页脚不占打印空间，防止表格刚好结束于页底时生成空白尾页。

单元回归检查多行表头及正文中表头的分组。真实来源 `table-source.docx` 包含原生 `w:tblHeader` 和 65 行正文；浏览器打印生成 `table-print.pdf`，PDF.js 逐页文字保存在 `print-page-evidence.json`。每个实际内容页均包含重复表头，最后一行正文完整保留。初次测试发现空白尾页，隐藏空页眉/页脚后复跑通过。

编辑器分页现按实际行高拆分表格，页间装饰使用合法的 tr/td，纵向合并关联行归为同组，不在合并区域中插入分页空白。测量时排除这些装饰行，避免重复重算计入空白。65行真实DOCX导入后，实际出现多个页面、无超高溢出、表格正文未改变；布局截图为 `table-page-layout.png`。第一次测量未穿过表格外层容器，回归发现后已修正并重建验证。

编辑器现为后续页重复表头预留实际高度，并将初始表头与第一行正文保持。重复表头使用只读视图装饰，不写入DOCX正文。表头文字编辑后重复区域同步，撤销重做及两次DOCX重开通过；原生正文只包含一次表头文字。明暗/320px截图及表头与后续正文行几何、只读标题行命令检查通过。分页模型8项、相关浏览器4项通过。

重复区域的装饰行使用 inert 隔离交互。真实DOCX来源包含超链接，测试为重复链接设置tabindex=0并调用focus，确认它仍不能获得焦点；原始正文链接及文件属性保留。此最后修正后相关四项浏览器流程全部复跑通过。

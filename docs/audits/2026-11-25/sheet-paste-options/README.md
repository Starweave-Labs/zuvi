# Excel 跳过空白与运算粘贴 X012 验收切片（2026-11-25）

选择性粘贴新增“跳过空白单元格”和无/加/减/乘/除选项。跳过依据来源实际空输入；格式或链接元数据不使空白成为有值。零、布尔、空白文本、显式空字符串和返回空字符串的公式都不被跳过。被跳过目标不进入更新批次，其原内容、格式、链接、保护或数组保持原样。复制合并结构时，完整来源合并单元格按一个单位处理；跳过造成部分目标合并重叠时整次拒绝。

算术接受当前模型的数字、布尔值（1/0）和真正空白（0），文字标识不隐式转换为数字。目标公式以组合表达式保留；仅值模式使用复制时冻结的源值，其余内容/公式模式重定位来源公式并使用最终结果。保留文本数字格式时用数值常量公式保持运算结果类型。仅格式、列宽不能组合运算；列宽也不按单元格跳过空白。算术实际涉及合并或任何目标数组区域时整批拒绝。

整个批次计算并完成数据验证后才交给宿主。零除数、无效或溢出结果、保护/数组/合并冲突、阻止型验证均不产生部分写入或新增历史。每次成功应用可以一次撤销/重做；错误显示在弹窗可修正。只读/禁用时选项和应用均禁用，保留配置草稿，取消/Escape 不写入。

Ctrl/Command+C 显式捕获虚拟矩形选区，优先通过用户触发的原生 copy 命令写入普通文本和内部 MIME；不支持该路径时尝试现代文本剪贴板，内部快照始终可供选择性粘贴。有效单元格草稿先提交并使用最新文档捕获，无效草稿不覆盖上一快照；禁用和 IME 事件不执行键盘复制，只读允许复制。原生 XLSX 的 String 空值导入为显式空串标记，保存重开后仍可再次粘贴并区别于真正空白。

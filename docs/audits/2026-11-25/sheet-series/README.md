# Excel 序列停止值 X017 验收切片（2026-11-25）

序列支持向下/向右、数字/日期/文本尾数、一个或两个种子、默认/指定/推算步长和可选停止值。包含停止端点，不能整步到达时填到边界前；停止值留空时保留原来的填满选区行为。每列/每行独立计算，保留种子，停止后的单元格不进入修改批次。已达到/超过边界的轨道不新增内容，设置停止值时不接受零步长。

数字按种子/指定步长精度计算，避免 0.1 等常见二进制尾数。日期使用整数天步长，停止值接受有效 ISO 日期或 Excel 序号；ISO 日期按当日零点比较，序号可保留时间分数，Excel 虚构序号 60 不能转入 ISO 日期序列。文本接受同前缀标签或非负整数尾数，保留补零标识；显式数字/科学记数法停止值也可使用。

整批构建后才提交。实际目标包括已填充但值相同的单元格，排除边界后的尾部，用于数据验证提示。原有尾部内容、格式、超链接、合并、保护与数组定义不写入；实际目标遇到合并、保护、数组结果或阻止型数据验证时全部拒绝。一次完整应用对应一次撤销/重做。

停止值使用 ZUVI Input，错误草稿留在弹窗可修正。只读/禁用期间输入与应用均禁用，草稿保留；取消/Escape 不写入。当前实现是线性序列，增长序列及工作日/月/年单位等策略仍未补齐。

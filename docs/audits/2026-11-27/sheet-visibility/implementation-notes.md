# X030 行列隐藏与显示（2026-11-27）

原始验收为“隐藏列、选区显示、全表显示与键盘导航”，六项共通要求保持原文。当前补齐所选行/列隐藏、选区显示及全部显示六个 ZUVI 入口。隐藏与显示保留单元格、公式、行高列宽及 auto/fixed 身份，筛选继续独立工作。

选区隐藏后光标移到可见位置；存在可见部分的合并单元格仍可聚焦。普通方向键、Shift 扩展和 Home/End 跳过隐藏行列，跨合并区域后继续寻找可见单元格。命令沿用既有事务、编辑草稿和权限守卫；组合输入期间不接受变更，非法编辑可用 Escape 恢复。

原生 XLSX 继续使用标准 hidden、行高、列宽和 customHeight 属性。仅靠单个原生 hidden 无法区分手动与筛选的重叠，保存时额外写入现有 ZUVI 命名空间下的可忽略 manualHiddenRows 属性；导入时要求该行仍具有真实原生隐藏标志，外部取消隐藏不会被陈旧标记重新覆盖。无该属性的普通外部文件沿用原筛选/手动推断。旧工作区缺失布局元数据时，原索引先经过结构编辑映射，再恢复手动隐藏身份。自动行的导出缓存允许按既有布局刷新，手动隐藏命令不将其改成固定行高。

原生回归4项：两轮保存重开、外部取消隐藏、非法元数据拒绝且原字节不变、旧工作区插入行后的身份及引用迁移。真实 Chromium 流程从原生来源导入，经隐藏、单次撤销重做、两轮下载重开、选区/全部显示与筛选清除，再核对尺寸、公式、XML 和只读入口；浅色/暗色及320px均有截图。
